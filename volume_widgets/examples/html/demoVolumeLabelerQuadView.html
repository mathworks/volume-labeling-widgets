Volume Labeler Widget (Quad View)

VolumeQuadLabeler is an extension of VolumeLabeler that adds:
  • SlicePlaneViewer
  • Two VolumeViewers that show the additional side and top views

Create the widget

f = uifigure;
f.Position(3:4) = [900 500];
g = uigridlayout(f,[1 1]);
w = wt.VolumeQuadLabeler(g);

Change the 3D slice being displayed

w.Slice3D = [114 126 8];

Creating Annotation Labels Programmatically Using the Mouse

Annotation labels in VolumeQuadLabeler behave the same way as they do in VolumeLabeler. See the demo for VolumeLabeler to learn how to work with annotations.
