Volume Labeling App

An example app for labeling a volume (3D image stack or DICOM) is provided.

Manual Code Alternative App

Alternatively, you can also develop these apps directly, outside of App Designer, using hand-code. This approach may be useful for more complex apps. Plain code files may provide a better source control experience, and modularizing the app into components also facilitates testing and maintainability.
This syntax launches the hand-code version of the app, which is stored inside the +handCode folder:
vAppHC = handCode.VolumeLabelingApp
vAppHC =
